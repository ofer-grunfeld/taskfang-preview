Common problems

The total says a folder “could not be opened”

Windows did not let the app read that folder, usually because your user account has no permission for it, or because it is on a network drive or USB disk that is not connected. Hover over the orange warning to see which folders. Fix the access (or connect the drive) and add the folder again.

Some files show “In cloud (not downloaded)”

These are OneDrive files that exist only online. Turn on Download cloud-only files and add the folder again. OneDrive will download them first, which can take a while for many files.

A file shows “Can't open”

Another program is holding the file locked, or you don't have permission to read it. Close the program that has it open and add the file again.

“Couldn't copy” when clicking Copy total or Copy table

Another program was using the Windows clipboard at that moment. Wait a second and click again.

Excel export fails with a message

Usually the previous export with the same name is still open in Excel. Close it in Excel, or save the export under a different name.

The count differs from my PDF reader

Please tell us. That is exactly the kind of problem we want to fix. Include the file if you can share it, or at least the numbers you see in both programs.

The log file

Each app keeps a small log on your PC that helps us understand problems. To find it, open the app, click About, then Open log folder. It is also in %LOCALAPPDATA%\TaskFANG\<app name>\logs.

The log may contain the names of files and folders you worked with. It is never sent anywhere automatically. Only attach it to an email if you are comfortable sharing those names.
